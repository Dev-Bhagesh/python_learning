# Bank Account Management System

A simple Python command-line project for managing bank accounts and performing basic banking operations.

## Features

- Create bank accounts with unique IDs.
- Deposit and withdraw money.
- Validate transactions and prevent insufficient-balance withdrawals.
- Protect account balances using encapsulation.
- Handle errors using custom exceptions.
- Manage accounts through a command-line interface.

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- UUID
- Custom Exceptions

## How to Run

Run the program from your project folder:

```bash
python main.py
```
