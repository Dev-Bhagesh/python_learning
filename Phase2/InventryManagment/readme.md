# Inventory Management System

A simple Python command-line project where users can create characters, log in, and manage their in-game inventory.

## Features

- Create a character with a name, age, role, and password.
- Log in to an existing character.
- Add and remove weapons and potions.
- Store character profiles and inventory data using JSON.
- Handle invalid user input and common errors.

## Technologies Used

- Python
- JSON

## How to Run

1. Install Python on your computer.
2. Open the project folder in your terminal.
3. Run the program:

   ```bash
   python main.py
   ```
