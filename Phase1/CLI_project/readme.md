# Personal Expense Tracker

A simple Python command-line application for tracking and managing personal expenses.

## Features

- Add new expenses with unique IDs.
- View all recorded expenses.
- Search expenses by name.
- Calculate total expenses.
- Delete individual expenses or all expenses.
- Save expense data in a file for future use.

## Technologies Used

- Python
- File Handling

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   ```bash
   python main.py
   ```
